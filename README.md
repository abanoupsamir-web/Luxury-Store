
# ⌚ Luxury Store - Premium Watch E-Commerce

A sleek, minimalist, and fully responsive e-commerce web application dedicated to luxury watches. This project focuses on delivering a sophisticated user experience using clean, modern **Vanilla JavaScript**.

▶️ **[Live Demo Link](https://abanoupsamir-web.github.io/Luxury-Store/)**

---

## ✨ Features

* **Premium Style:** Dark, elegant, and minimalist design tailored specifically for high-end luxury brands.
* **Dynamic Shopping Cart:** Add, remove, and update watch quantities in real-time with automatic total price calculation.
* **Advanced Product Filtering:** Filter luxury watches smoothly by brand, price, or category without reloading the page.
* **Fully Responsive Layout:** Optimized performance and pixel-perfect view across desktops, tablets, and smartphones.
* **Persistent Cart (Optional):** Saved cart items using `localStorage` so items remain even after refreshing.

---

## 🛠️ Tech Stack

* **Structure:** HTML5
* **Styling:** CSS3 / Custom Animations ( Tailwind )
* **Logic & Interactivity:** Vanilla JavaScript (ES6+)
* **Deployment:** Vercel

---

## 🚀 How to Run Locally

Follow these simple steps to get the project up and running on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project folder:**
   ```bash
   cd luxury-store
   ```
3. **Open the project:**
   Simply open the `index.html` file in your preferred browser, or use the VS Code **Live Server** extension for a better experience.
